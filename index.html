1. Supabase 서버 연결 설정

Supabase SQL Editor에서 아래 쿼리를 1회 실행하세요:

CREATE TABLE IF NOT EXISTS rnd_user_storage (
  user_id UUID PRIMARY KEY,
  data JSONB NOT NULL DEFAULT '{}'::jsonb,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE rnd_user_storage ENABLE ROW LEVEL SECURITY;
CREATE POLICY "rnd_owner_policy" ON rnd_user_storage
  FOR ALL USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
2. 내 계정으로 로그인 / 회원가입
