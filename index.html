Supabase 연결 정보를 설정하고 로그인하시면, 모든 프로젝트와 작성 데이터가 클라우드에 자동 동기화됩니다.

1. Supabase 프로젝트 설정

Supabase SQL Editor에 아래 쿼리를 1회 실행하세요:

create table if not exists public.rnd_projects (
  id text primary key,
  user_id uuid references auth.users not null,
  name text,
  type text,
  data jsonb,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);
alter table public.rnd_projects enable row level security;
create policy "Users manage own projects" on public.rnd_projects
  for all using (auth.uid() = user_id);
